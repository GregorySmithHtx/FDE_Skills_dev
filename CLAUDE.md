# Repo purpose

This repo is Greg's living FDE (Forward Deployed Engineer) skills tracker —
not a software project. It exists to answer, over time: what FDE-relevant
skills does Greg already have, what's rusty, what's a true gap, and what's
he done about it.

- `SKILLS_ASSESSMENT.md` — current skill-pillar assessment. Update the
  pillar levels/evidence when something materially changes (a project
  demonstrates a skill, a weak area gets real practice, etc.).
- `LEARNING_ROADMAP.md` — phased plan from fundamentals to an FDE-style
  capstone. Check items off as completed; don't rewrite the phases unless
  Greg's goals change.
- `PROGRESS_LOG.md` — dated, append-only notes on what actually happened.
  Add an entry whenever a session here (or referenced from another project)
  produces a real update, newest first.

## Working here

- Keep updates grounded in evidence — a claimed skill needs something built
  or practiced, not just time passed.
- Greg's stated goal (2026-08-16): exploring whether FDE is the right fit,
  not actively applying. Don't push urgency he hasn't asked for.
- This tracking is meant to stay active "until [he] change[s] my mind or
  have landed a role of that type or similar" — keep it live rather than
  treating it as a one-time exercise.
